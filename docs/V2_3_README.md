# 漠翠进销存 v2.3

本次按当前需求改动：

1. 添加/编辑商品时，分类必须选到子分类。
   - 一级分类不能直接保存。
   - 未分类不能保存。
   - 选择错误时会提示并重新打开分类选择。

2. 商品详情新增“商品往来”。
   - 最近销售：销售时间、数量、销售给谁、订单号、金额。
   - 调借记录：借出给谁/借入自谁、调借时间、数量、未处理数量、状态。
   - 点击调借记录可以直接进入关联调借详情。

3. 首页精简。
   - 保留：今日成交、今日毛利、本月成交、本月毛利。
   - 功能按钮只显示 2-3 个字：销售、商品、调借、过手、货源、外部货、盘点、内容。
   - 删除按钮说明文字、操作脚注、商品仓库统计区。
   - 首页不再显示调借逾期/到期提醒。

4. 调借逾期红色提醒仍留在调借页面，不改调借业务逻辑。

覆盖：
- public/index.html
- public/sw.js

新增：
- public/business-flow-v2.3.js
- public/business-flow-v2.3.css

不修改：
- app.js
- sync-v2.js
- cloud.js
- D1 / Worker 同步内核

这样避免影响已稳定的本机优先和增量同步。
