# v3.1.6 更多页最终修复

根因：
v3.1.5 在旧 renderMore 完成之前先写入了 3×2 页面，并给 main 加了完成标记；
随后旧 renderMore 又把长列表覆盖回来，而后续定时修复因为看到完成标记直接退出。
所以最终仍然看到旧长列表。

本版：
- 不再猜页面渲染需要多少毫秒。
- 只监听 #main 的直接子节点变化。
- 检测到旧 `.more-group` 长列表真正出现后，再替换成最终 3×2。
- 替换完成后 `.more-group` 不存在，因此不会形成 MutationObserver 循环。
- 更多只保留：客户、销售单、盘点、流水、货源、设置。
- 一屏显示，无需上下滑。
- 保留商品详情“商品往来”去重。
- index.html 把脚本/样式 URL 提升到 v=3.1.6。
- Service Worker 使用新缓存名，避免 iPhone 继续加载旧 3.1.1 文件。
- 不删除任何业务数据。
