# 功能验收清单

## 商品与库存

- [ ] 新增商品并上传图片。
- [ ] 商品编码自动生成。
- [ ] 复制商品时不重复增加原商品库存。
- [ ] 名称、编码、颜色和备注可模糊搜索。
- [ ] 入库、出库和盘点均形成库存流水。

## 销售

- [ ] 客户姓名输入一个字出现历史匹配。
- [ ] 多选商品、修改数量和销售单价。
- [ ] 折扣、优惠金额、抹零、本次实收可用。
- [ ] 撤销售单恢复库存。
- [ ] 恢复销售单重新扣库存。
- [ ] 撤销单可复制后重新开单。

## 调借和还货

- [ ] 借调人输入一个字出现历史匹配。
- [ ] 同一借调人再次借货时显示全部未完成记录。
- [ ] 初次借货图片、微信截图和文字备注保留。
- [ ] 全部归还、部分归还、单件归还可用。
- [ ] 每一次还货独立保存图片、时间、数量和备注。
- [ ] 超过 30 天未处理的借调记录飘红。

## 借调售出

- [ ] 借出商品售出不重复扣仓库库存。
- [ ] 自动生成正式销售单。
- [ ] 销售撤销后恢复为借调未处理。
- [ ] 销售、库存流水、利润和报表联通。

## 云端

- [ ] 手机与电脑使用同一网址和密码。
- [ ] 新增商品后另一设备刷新可看到。
- [ ] 图片在另一设备可查看。
- [ ] 云端备份列表可打开和恢复。
