# 安全与备份

## 登录

- 首次初始化需要一次性初始化码。
- 管理密码使用 PBKDF2-SHA256 加盐保存，不以明文写入数据库。
- 会话 Cookie 设置为 HttpOnly、Secure、SameSite=Strict。
- 登录错误次数过多会临时限制尝试。

## 图片

- 商品、借货、还货和签字图片存放在私有 R2。
- 图片必须在登录状态下通过 Worker 接口读取。
- 系统不会把 R2 存储桶设置为公开。

## 云端版本

- 每次同步生成独立业务快照。
- 自动保留最近 50 个版本。
- 恢复旧版本时会生成新的版本，不直接覆盖删除历史记录。

## 独立备份

建议每周：

1. `更多 → 数据与设置`。
2. `导出完整 JSON 备份`。
3. 保存到 iCloud Drive。

重大盘点、批量导入、批量修改或清空数据之前，先导出一次 JSON。
