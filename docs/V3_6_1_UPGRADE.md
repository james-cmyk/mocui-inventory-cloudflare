# v3.6.1 升级说明

本版本只修正 iPhone 快捷保存的剪贴板内容与 openWechat 判断，不改变库存、销售、调借、D1、R2 数据结构。

## 预期行为

### 下载
- 保存：全部原图 + 原视频
- 剪贴板：只复制朋友圈文案
- 不自动打开微信

### 店铺1:1
- 保存：该商品全部 1:1 店铺图
- 剪贴板：小红书正文 + 话题（不含标题）
- 不自动打开微信

### 分享 → 朋友圈
- 保存：全部朋友圈原图
- 剪贴板：只复制朋友圈文案
- 自动打开微信

## 快捷指令顶部正确结构

1. 获取「快捷指令输入」内容（这里访问 ERP 传来的临时任务 URL）
2. 从「URL 的内容」获取字典
3. 在「字典」中获取 `files`
4. 重复每一项 → 取 `url` → 获取 URL 内容 → 保存到照片
5. 从同一个「字典」读取 `copyText` / `message` / `openWechat`

注意：ERP 传给快捷指令的是临时任务 URL，不是直接传 JSON。
