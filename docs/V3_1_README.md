# 漠翠进销存 v3.1 — 商品快速索引第一阶段

基于已稳定的 v3.0.3 继续，不改库存/销售/调借核心事务。

## 这次真正解决的性能点
1. 商品页不再每次直接读取包含大图片字段的完整 products 记录来做列表。
2. 新建独立轻量索引 `mocui_perf_v31`，只保存商品列表需要的字段。
3. Base64 原图绝不复制进快速索引；已经是 R2/API 地址的图片只保存地址。
4. 商品页先立即画出页面结构，再读快速索引，不再让上一页长时间停留。
5. 默认每次只渲染 30 件商品；点“继续显示”再增加 30 件，避免几百/几千个 DOM 和图片同时进入页面。
6. 搜索、分类、库存筛选在轻量索引上完成。
7. 商品新增/编辑/删除后自动维护索引。
8. 云端同步后在后台空闲时校准索引，不阻塞当前操作。
9. 导出商品时才读取完整商品数据，因为导出属于低频操作。

## 第一次打开
第一次升级会建立一次快速索引。如果商品很多，商品页会显示“首次建立快速索引”。
完成后后续进入商品页才是正常 v3.1 速度。

## 没有做的事情
- 没有修改正式 products 数据。
- 没有删除或压缩现有原图。
- 没有修改库存流水。
- 没有修改销售/调借。
- 没有改 v3.0.3 导航稳定机制。
