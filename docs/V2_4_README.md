# 漠翠进销存 v2.4｜全局适度精简

基于 v2.3.1（首页 3 列布局）继续优化。

## 本次原则
不是“砍功能”，而是：
- 少一点解释文字
- 少一点大卡片和空白
- 重要数据继续保留
- 风险/备份/库存相关提示不删除
- 销售、库存、调借、同步逻辑不改

## 页面调整

### 商品
- 顶部库存统计保留但压缩
- “批量上传 / 分类管理 / 导出商品”改成短按钮：导入 / 分类 / 导出
- 搜索和分类筛选更紧凑
- 商品列表行高略收紧

### 销售
- 状态筛选和搜索保留
- 销售卡片减少空白，订单/客户/金额/状态继续显示

### 调借
- 首页式大段说明改为一句短提示
- “外部同行货 / 寄售流转（测试）”改成小入口“外部货”
- 未处理 / 部分处理 / 超期 3 个指标保留
- 超期红色提醒继续保留在调借页
- 调借记录压缩行高，不删关键信息

### 报表
- 顶部模式改成：销售 / 过手 / 外部货 / 助手
- 日期范围保持完整，但支持横向滑动，减少多行拥挤
- 报表内容、经营助手分析不删除

### 更多
- 仍按业务场景分组
- 每个功能的说明缩成一行
- 数据安全提示缩短，但仍保留

### 客户 / 盘点 / 流水 / 日志 / 体检
- 搜索框与列表更紧凑
- 盘点和日志的说明缩短
- 体检关键指标继续保留

### 设置
- 云同步、备份、合同抬头、危险操作全部保留
- 只压缩卡片间距和提示文字视觉占用
- 不隐藏任何安全功能

### 弹窗 / 表单
- 字段间距、帮助文字、提示框适度收紧
- 调借仍保持“基本信息 → 图片备注 → 商品数量”三步逻辑
- 不改变保存、库存、同步行为
