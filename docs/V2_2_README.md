# 漠翠进销存 v2.2 业务整理与交互优化

覆盖：
- public/index.html
- public/sw.js
- public/pwa.js

新增：
- public/business-ux-v2.js
- public/business-ux-v2.css

功能：
1. 更多 → 数据整理 → 检查重复商品
   - 只合并高置信重复：相同货号 / 秦丝条码 / QinSilk sourceKey
   - 只同名但货号不同的不自动合并
   - 库存取最新快照，不相加
   - 重复项归档，不硬删除
   - 销售 / 调借 / 盘点引用统一到主商品
   - QinSilk 初始/库存同步流水保留在归档项，避免重复流水叠加
   - 以后 QinSilk 商品导入完成后自动执行同类高置信去重

2. 首页“今日成交构成”
   - 正式 / 调借账
   - 过手差价账
   - 外部同行货账
   - 三类成交额合计进入今日总成交
   - 报表仍分账

3. 返回体验
   - 所有非一级页面改成“‹ 返回”胶囊按钮
   - 主屏幕 PWA 支持从左边缘向右滑返回
   - 弹窗、键盘、一级页面不触发
   - Safari 浏览器模式不抢系统原生手势

4. 应用内更新
   - 更多 → 应用与更新 → 检查更新
   - 刷新应用缓存
   - 不清除业务 IndexedDB / Outbox / 商品销售调借数据

上线后建议：
- 先进入“更多 → 检查重复商品”
- 看系统报告多少组，再确认整理
- 整理后回商品页确认重复项只剩一个
- 首页检查三账成交构成
- 进入任意二级页测试左边缘右滑返回
