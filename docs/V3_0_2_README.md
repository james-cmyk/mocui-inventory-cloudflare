# v3.0.2 导航稳定性修复

现象：连续点击 概况→商品→调借→报表→更多，第二轮可能出现旧页面内容、整页半透明或白屏。

根因：原 navigate() 允许多个异步 render 同时执行。navigationToken 只在 render() 完成后判断，
但旧 render 在判断之前已经可能改写 #main，因此快速切页时会发生“旧页面覆盖新页面”的竞态。
同时 `.route-changing` 会把旧页面降到 35% 不透明度，竞态/慢查询时看起来像整页虚化。

修复：
- 任意时刻只允许一个页面 render 修改 #main。
- 连续点击时只保留最后一次导航请求。
- 当前渲染完成后，下一帧再执行最后一次请求。
- route-changing 不再把整页降到 35% 透明度。
- pageshow/focus/回到前台时清除异常遗留的 route-changing 状态。
- 保留 v3.0 增量同步、销售配饰成本、图片延迟加载和 v3.0.1 UI Observer 修复。
- 不修改商品、销售、调借、库存和云端数据。
