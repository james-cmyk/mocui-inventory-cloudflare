# 漠翠进销存 v3.0 性能基础版

这不是把功能推倒重做，而是在 v2.4 之上替换同步内核并增加性能层。

## 已完成
- 同步从“每次扫描全部业务表并重新哈希”改为“本机写入变更日志 + 只同步变动记录”。
- 保留原 `/api/sync/v2/*` 服务端协议，所以 Worker/D1 暂时不用迁移。
- 首屏不等待云端同步；登录成功后后台同步。
- 同步数据库连接复用，远端拉取时一次缓存 outbox/conflict，避免每条远端记录反复 getAll。
- 从 v2 升级后会做一次兼容全扫描；第一次可能仍慢，完成后进入 v3 日志模式。
- 图片默认 lazy loading + async decoding，列表图片不抢首屏资源。
- 销售开单增加“配饰成本”“其他直接成本”。
- 毛利公式更新为：成交额 - 商品成本 - 配饰成本 - 其他直接成本。
- 销售详情显示商品成本、配饰成本、其他成本、实际毛利。
- 没有增加“手填额外利润”，避免利润重复计算。

## 重要
升级后第一次打开，v3 会为兼容旧同步状态执行一次全量检查，因此第一次仍可能比后续慢。等顶部变成“已同步”后关闭再打开，才是正常 v3 性能表现。
