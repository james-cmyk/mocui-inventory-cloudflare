# 「漠翠保存素材」iPhone 快捷指令设置

> 只需建立一个快捷指令。它同时负责原图+视频、店铺1:1、朋友圈。

## 名称

`漠翠保存素材`

## 动作清单

1. **获取URL内容**
   - URL：选择变量「快捷指令输入」
2. **设定变量**
   - 名称：`任务`
3. **获取字典值**
   - 从「任务」获取 `files`
4. **重复每一项**
5. 在重复内部添加 **获取字典值**
   - 从「重复项目」获取 `url`
6. 添加 **获取URL内容**
   - URL：上一步的 `url`
7. 添加 **存储到照片相簿**
   - 输入：上一步下载的内容
8. **结束重复**
9. **获取字典值**
   - 从「任务」获取 `copyText`
10. 添加 **如果**
   - copyText 有任何值时 → **拷贝至剪贴板**
11. **获取字典值**
   - 从「任务」获取 `message`
12. 添加 **显示通知**
   - 通知内容：message
13. **获取字典值**
   - 从「任务」获取 `openWechat`
14. 添加 **如果**
   - openWechat 为真 → **打开App** → 选择「微信」

## 第一次运行

系统可能询问：

- 是否允许快捷指令访问 `erp.mocuiyu.com`
- 是否允许写入「照片」

请选择允许。

## 测试

先用一个 2 张原图 + 1 个视频的商品：

1. 内容工作台点「下载」
2. 应自动跳到「漠翠保存素材」
3. 等待通知“商品素材已保存：2张图片 + 1个视频”
4. 打开照片确认三项都在
5. 再测试「店铺1:1」是否保存两张方图
6. 再测试「分享 → 朋友圈」是否复制文案、保存原图并打开微信
