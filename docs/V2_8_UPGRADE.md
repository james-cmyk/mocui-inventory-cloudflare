## 使用路径
部署后进入：`更多 → 秦丝数据导入`。

1. 选择秦丝 Excel，可同时选择商品、客户、库存、销售文件。
2. 查看自动识别和预览结果。
3. 点击“先导出完整 JSON 备份”。
4. 点击“开始安全导入”。
5. 导入完成后下载结果 CSV，并检查商品数量、客户数量与库存体检。
