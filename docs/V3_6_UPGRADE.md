# v3.6 升级说明

## 升级文件

覆盖现有仓库中的：

- `src/index.js`
- `public/app.js`

不需要修改 `wrangler.jsonc`，D1 会自动创建 `shortcut_tasks` 表。

## 第一次只需设置一个快捷指令

名称必须为：`漠翠保存素材`

建议从系统内进入：**更多 → iPhone快捷保存**，按页面动作清单设置。

动作结构：

1. 获取 URL 内容（URL = 快捷指令输入）
2. 设定变量「任务」
3. 从「任务」获取字典值 `files`
4. 重复每一项
5. 从重复项目获取 `url`
6. 获取 URL 内容
7. 存储到照片相簿
8. 结束重复
9. 从「任务」获取 `copyText`，有值时拷贝至剪贴板
10. 从「任务」获取 `message`，显示通知
11. 从「任务」获取 `openWechat`，为真时打开微信

第一次运行时允许访问 `erp.mocuiyu.com` 和照片。

## 使用方式

- **下载**：一次点击 → 快捷指令 → 原图和原视频直接写入照片。
- **店铺1:1**：一次点击 → 全部图片完整构图适配为 1:1 → 快捷指令写入照片。
- **朋友圈**：分享 → 朋友圈 → 文案复制 + 原图保存 + 自动打开微信。

快捷任务 20 分钟失效；公开任务只能访问本次被授权的素材。
