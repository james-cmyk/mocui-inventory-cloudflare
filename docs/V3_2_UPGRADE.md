# v3.2 升级说明

本版本基于 v3.1 代理素材中心继续升级，不删除商品、库存、销售、客户、调借或既有代理分享数据。

## 主要变化

1. 内容工作台由统计卡片改为高频操作商品流。
2. 分享无需返回后再点“已发”，点击平台分享即记录本次分享时间。
3. 视频号不再单独记录；朋友圈视频/视频号继续用秒剪。
4. 小红书分享使用原视频，文案会自动追加与商品和当前正文相关的标签候选。
5. 小红书店铺 3:4 / 1:1 图不再硬裁切，改为完整构图适配画布。

## 关于“小红书热门标签”

v3.2 先实现“自动分析 + 相关热词池匹配”：从商品资料和当前文案提取料种、品类、产地、购买决策等语义，再从本地和田玉热词池中选择最相关的 6 个标签。

这不是小红书实时榜单 API，因此界面不会把它冒充“实时热度”。后续若能获得稳定、合规的官方热词数据源，可直接替换热词池，分析逻辑不用重做。

## 部署

将本包同名文件覆盖到现有 GitHub 仓库，Commit 后 Push 到 `main`。Cloudflare Git 集成正常时会自动部署。

建议部署后：Safari 下拉刷新一次，并完全关闭桌面 PWA 后重新打开，以确保新的 Service Worker 缓存生效。
