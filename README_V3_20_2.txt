漠翠进销存 v3.20.2 — iPhone 真机第二轮修复

根据 v3.20.1 部署后的 5 张真机截图，本轮只修仍然明确存在的问题：

【已确认并修复】
1. 顶部标题/副标题/同步状态/+ 按钮跑到 iPhone 状态栏下面
   - 根因：v3.20.1 恢复 relative topbar 后，没有把 safe-area-inset-top 重新计入 topbar 自身高度。
   - 修复：topbar 重新占用 Dynamic Island/状态栏安全区，但保持 relative，不再使用 sticky。

2. 所有主页面顶部标题几乎看不到
   - 概况、商品、调借、报表、更多都会一起恢复。
   - 商品页和调借页右上角 + 也会回到正常位置。

3. 首页“外部货/盘点”出现小图标，而销售/商品/调借等没有
   - 根因：自动图标规则只命中了部分按钮。
   - 修复：首页快捷入口统一为纯文字，不再出现零散小图标。

4. 更多页双图标
   - 继续锁定为单图标，防止自动装饰器再次插入 PNG。

5. 报表
   - v3.20.1 已把报表主体错位修正。
   - v3.20.2 明确锁住日期筛选条为正常文档流，避免顶部安全区恢复后再次错位。

【本轮没有改】
- DB_VERSION
- IndexedDB 正式业务库
- 销售/库存/调借/配饰
- 毛利和报表计算
- CloudSync / Outbox
- R2 图片
- 统计预计算
- 商品/销售/调借正式记录

部署后重点检查：
A. 概况：顶部“漠翠进销存 + 副标题 + 已同步”
B. 商品：顶部“商品管理 + 已同步 + +”
C. 调借：顶部“调借货管理 + 已同步 + +”
D. 报表：顶部“统计报表”，日期条不能遮挡数据
E. 更多：顶部“更多”，6 个入口保持单图标
