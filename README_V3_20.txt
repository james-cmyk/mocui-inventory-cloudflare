漠翠进销存 v3.20.0 — iPhone 页面级精修

本版继续坚持“不动账本，只精修页面”。

页面级调整：
1. 首页
- KPI 卡和常用操作进一步压缩间距，信息层级更清楚。
- 保留 3 列/现有业务入口逻辑，不重排核心导航。

2. 商品
- 商品行更紧凑，缩略图加大到更适合玉石图库浏览。
- 搜索/筛选工具栏 sticky，长列表滚动后仍可快速筛选。
- 商品名称超长自动省略，避免挤坏价格/库存区域。

3. 销售/开单
- 表单卡片、字段间距、销售商品行重新适配手机。
- 小屏 iPhone 上复杂 form-row 自动改单列，减少误触。
- 主操作按钮视觉权重提高，但不改保存逻辑。

4. 调借
- 列表密度重新整理，状态标签保持一眼可读。
- 工具栏 sticky，长列表筛选更方便。

5. 报表
- KPI 和成本卡片压缩。
- 390px 以下成本区改 2 列，避免数字挤压。
- 表格支持顺滑横向滑动。
- 日期筛选 sticky。

6. 更多/设置
- 入口卡片进一步压缩，尽量保持一屏可扫完。
- 数据安全检查保持次级，不抢常用功能。

7. 交互细节
- 数字输入自动使用 decimal 键盘。
- 电话输入使用 tel 键盘。
- 自动补充按钮 aria-label 和图片 alt。
- 页面识别使用 appState + DOM signature，不移动业务 DOM。

安全边界：
- 不修改数据库版本、销售、库存、调借、配饰、统计、CloudSync、R2。
- 新增 iphone-pages-v3.20.css / iphone-pages-v3.20.js，可单独回退。
