# 漠翠进销存 v1.4 核心测试

已验证：

- 借调详情右上角低调显示“··· 凭证”入口。
- 可分别生成正式借调及委托销售协议、简版调拨/交接单。
- 自动带入借调人、商品编码、颜色、数量、商品备注和销售价责任价。
- 双方身份、期限、交接地点、结算和管辖字段可编辑。
- 责任价修改后合计金额实时更新。
- 甲乙双方签名板可手写和清除。
- 确认图片可多张上传并单张删除。
- 可复制微信明确确认文案。
- 可打印/存为 PDF、下载 HTML 副本。
- 保存后写入调借单 legalDocuments 历史，不覆盖原始借货与还货图片。
- 保存时生成合同内容校验值；HTTPS 环境下使用 SHA-256。
- 合同抬头可在“更多 → 数据与设置”中保存并自动带入。
- 旧版商品、销售、库存、调借和还货数据结构兼容。
