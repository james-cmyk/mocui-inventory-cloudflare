# 漠翠进销存 v1.4

手机优先、自用、本地数据库版进销存系统。商品、销售、客户、调借、库存和合同凭证保存在当前设备浏览器的 IndexedDB 中，支持离线使用。

## 主要功能

- 商品新增、编辑、复制、图片、自动编码、分类、模糊搜索、CSV 批量导入导出。
- 入库、出库、盘点、库存流水、商品销售明细。
- 多商品销售开单、优惠、抹零、实收、撤销、恢复、复制重开。
- 销售客户姓名历史模糊匹配。
- 借出、调入/借入、多次部分归还、全部归还、单件归还。
- 每次借货和还货分别保存图片、时间和文字备注。
- 借调商品售出后自动关联销售单、库存流水、利润、客户和商品统计。
- 经营概况、销售报表、利润分析、库存汇总、客户排名和商品排名。
- 完整 JSON 备份与恢复。

## v1.4 借调合同和调拨凭证

借调详情中“借调信息与原始图片”右侧有一个低调的“··· 凭证”入口，平时不影响操作。

可生成：

1. 《货品借调及委托销售确认协议》
2. 《货品调拨/交接确认单》

系统自动带入借调人、商品名称、编码、颜色、数量、商品备注和责任价，并支持：

- 双方真实身份、电话、地址和微信号
- 交接日期、归还日期和交接地点
- 售出结算期限、违约责任和争议管辖
- 甲乙双方屏幕手写签名
- 签字页、按指印照片或微信确认截图留档
- 自动生成微信明确确认文案
- 打印或由浏览器存为 PDF
- 下载独立 HTML 副本
- 保存合同快照和内容校验值
- 多份合同/交接凭证历史记录

## 法律提示

本系统提供的是交易凭证模板和证据留存工具，不是律师法律意见，也不保证合同必然有效或诉讼必然胜诉。屏幕手写签名不当然等同于经身份认证、防篡改的可靠电子签名。高价值货品建议使用纸面签字并按指印，或使用合规第三方电子签约服务。

## 数据安全

- 当前版本不自动上传服务器，也不会自动跨设备同步。
- 身份证号、签名、聊天截图等敏感信息只保存在当前浏览器，请妥善保管手机。
- 浏览器清理网站数据可能删除全部数据，建议每周导出一次完整 JSON 备份。
- 升级前先备份，并继续使用同一个 HTTPS 域名和浏览器。
